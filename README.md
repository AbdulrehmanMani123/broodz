# BrOOdz website

A single-page static site. Everything (images, styles, game) lives in `index.html`.

## Deploy on Vercel
1. Put these files in a GitHub repository (index.html at the top level).
2. On vercel.com choose Add New, Project, import the repository.
3. Framework preset: Other. Leave the build command and output directory empty. Deploy.

Every time you replace `index.html` in GitHub, Vercel redeploys automatically.
